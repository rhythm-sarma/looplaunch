# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Structure of a Directive
- **Goal**: What needs to be accomplished
- **Inputs**: Required configuration, parameters, or data sources
- **Tools/Execution Scripts**: The Python script(s) in `execution/` to invoke
- **Outputs**: Deliverables (Google Sheets, Slides, external APIs) or intermediate data
- **Edge Cases & Learnings**: Updated over time as the system executes and anneals
